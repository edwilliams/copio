# Copio SDK — Vue 3 Example

Minimal Vite + Vue 3 + TypeScript integration of `<copio-scanner>`, listening to `copio:scan-complete` and exporting a PDF.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/edwilliams/copio/tree/master/examples/vue)
[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/edwilliams/copio)

## Run Locally

```bash
npm i
npm run dev
```

## Build

```bash
npm run build
```
