Copio SDK Theming & Design Tokens CPO-038

Demonstrating Dark, Light, Brand and Host-Overridden Themes with zero component code changes.

Layout:
Zero-Code Theming Contract: All <copio-scanner> web components encapsulate their styles inside Shadow DOM via adoptedStyleSheets, exposing public --copio-* CSS custom properties and ::part() anchors (scanner-root, header, viewfinder, shutter-dock, workbench, toolbar). Consumers toggle themes via the theme attribute or class with no JavaScript changes.

Dark Theme (Default)

theme="dark"
Tokens:
  • Surface: #131b26 / Backdrop: #0b0f17
  • Primary Accent: #38bdf8 (Sky Blue)
  • Radii: 6px / 10px / 14px

Light Theme

theme="light"
Tokens:
  • Surface: #ffffff / Backdrop: #f8fafc
  • Primary Accent: #0284c7 (Deep Sky)
  • Radii: 6px / 10px / 14px

Brand Theme (Emerald)

theme="brand"
Tokens:
  • Surface: #181b28 / Backdrop: #0f111a
  • Primary Accent: #10b981 (Emerald)
  • Radii: 4px / 8px / 12px

Custom Host Override

::part() & --copio-*
Custom Host Override:
  • Custom Accent: #f43f5e (Rose)
  • Custom Shadow Part styling on ::part(header)
  • Zero internal component modifications
